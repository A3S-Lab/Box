# A3S Box 指南

A3S Box 是本地 OCI 工作负载运行时。默认执行路径使用独立 Linux 客体内核的
MicroVM；在经过认证的 Linux 主机上，也可以显式选择共享内核 Sandbox。

运行时不会在两种隔离之间自动降级。主机无法执行请求时，会在写入运行时状态或
拉取镜像之前返回明确错误。

## 不变量

- 不传 `--isolation` 即选择默认 MicroVM。
- `--isolation sandbox` 是经过认证的 Linux 主机上的显式选择。
- 不支持的组合在产生运行时副作用之前失败。
- CLI、Rust、TypeScript、Python、Go 和集群适配器共享同一个本地状态所有者。
- 盒子生命周期使用代际围栏，陈旧句柄不能修改更新后的实例。
- SDK 与运行时应使用同一 A3S Box 发布版本。

## 选择入口

交互式排障和运维使用 CLI；应用程序和 CI/CD 使用
[原生 SDK](/sdk/)。两种入口操作相同的本地镜像、Sandbox、卷、网络、快照和日志，
不存在第二套远程控制平面。
